# powerquery-formatter

**Active development has moved to the
[microsoft/powerquery-language-services monorepo](https://github.com/microsoft/powerquery-language-services).**

For current installation, usage, and development instructions, see the
[formatter README](https://github.com/microsoft/powerquery-language-services/blob/master/packages/powerquery-formatter/README.md).

The npm package name remains `@microsoft/powerquery-formatter`, a TypeScript library for formatting
Power Query / M expressions and section documents. This migration does not deprecate or remove the package.

- [Formatter source](https://github.com/microsoft/powerquery-language-services/tree/master/packages/powerquery-formatter)
- [File issues in powerquery-language-services](https://github.com/microsoft/powerquery-language-services/issues)

Please direct new contributions to the monorepo.
